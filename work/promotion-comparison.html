집행 여부를 판단할 근거가 없던 유료 홍보

석사 이상 심리 전문가 대상 클래스를 학회 유료 메일링과 학회 게시판(무료)으로 홍보했습니다. 다음 기수의 유료 홍보 집행 여부를 판단해야 했지만, 홍보가 등록으로 이어졌는지 확인할 근거가 없었습니다.

Class A~E 다섯 기수에 같은 금액으로 유료 메일링을 집행하던 중, 단가가 22만 원에서 44만 원으로 인상된다는 통보를 받았습니다.

판단해야 할 것
다음 기수에 유료 홍보를 집행할 것인가

Class E (유료 메일링)Class F (유료 없음)Class A~D유료 메일링 발송 주

A~E 유료 메일링은 기수마다 같은 금액이고, Class F는 단가 인상 통보 후 유료 없이 무료 홍보만 진행했습니다.

한 시트 대신 원본과 분석을 나눈 데이터 구조

기존

신청자 정보와 홍보 내역이 6개 클래스, 여러 위치에 분산되어 있었습니다.

두 데이터 통합으로 세운 홍보 효과 판별 기준

석사 이상 심리 전문가는 학회 일정과 업무로 신청까지 시간이 걸릴 것으로 보고, 홍보 후 3주를 관찰 구간으로 설정했습니다.

AI는 분석 시트 설계와 해석 보조에 활용했고, 재검증 중 고정값 로직을 발견해 수식으로 전환했습니다. 데이터 통합, 학회 및 시점 대조 기준, 최종 해석은 직접 결정했습니다.

설명을 위해 재구성한 도식입니다. 판별 기준을 누르면 비교하는 칸이 표시됩니다.

비교 범위

무료 채널까지 비교 가능하도록 확장

홍보 주 계산

고정값으로 입력된 칸을 날짜만 넣으면 다시 계산되는 수식으로 전환 후 결과 검증

기간 겹침

유료, 무료 홍보 기간이 겹친 경우를 판단 보류로 따로 분류

핵심 판단

유료 홍보 집행 재개 여부의 판단 기준을 홍보 후 3주 내 대상 학회 소속자의 등록 변화와 전체 등록자당 비용으로 설정했습니다.

등록 저조 기수에서 증가한 등록자당 홍보비

A~E 기수의 유료 집행액이 같아, 등록자가 적은 기수일수록 비용 지수가 높게 나타났습니다. 매 기수 연속 상승한 것은 아닙니다.

Class A 대비 Class E의 비용 지수약 3.1배

홍보 중단 결정과 후속 분석에 남은 근거

1차 보고에서 분석 결과와 단가 2배 인상을 근거로 유료 홍보 중단을 직접 제안했고, 경영진이 채택해 이후 기수부터 유료 홍보 없이 진행했습니다.

유료 홍보 (학회 유료 메일링)

경영진의 중단 결정 근거로 채택

등록 급감 기수의 등록자 1인당 비용 약 3.1배, 유료 미집행 Class F 등록자 수 E와 동일

무료 홍보 (학회 게시판)

경영진의 채널 유지 결정 근거로 채택

3개 학회 게시 작업 10분 이내, Class E 등록자 7명 전원 무료 게시판 학회 소속

확인 범위

유료 홍보는 일부 학회에서만 진행됐습니다. 3주 구간의 등록 시점과 학회 소속을 비교한 관찰 자료로, 개별 등록을 특정 홍보에 완전히 귀속하거나 다른 요인을 통제한 실험은 아닙니다.

보완 설계

신청서에 유입 경로 문항을 추가해, 자기보고 경로와 관찰된 등록 시점을 대조하겠습니다. 두 정보가 일치하지 않는 신청자는 짧은 확인 질문으로 3주 구간과 소속 기준을 보정하겠습니다.
